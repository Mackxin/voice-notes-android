# 2026-11-16 工作日志

## 随手说 VoiceNotes（微信式语音速记安卓 App）

- 需求：点按打字、长按说话、左滑取消、右滑转文字编辑、松手自动转文字并发送；用阿里云百炼；开源 GitHub。
- 选型：百炼文件转写需公网 URL，改用 paraformer-realtime-v2 WebSocket 直接推 PCM（16kHz/16bit/mono，100ms 帧）；Kotlin 2.0.21 + Compose + OkHttp；API Key 运行时配置、不入库；笔记本地 JSON 文件。
- GitHub 扫描结论：gmyboy/VoiceRecord、JayYangSS/wechatRecorder（Java 老 UI）、shang-chuan-code/ChuanLink（带后端）均不适合直接复用，只作手势与鉴权参考，Compose 重写。
- 构建环境：复用同机已验证组合 AGP 8.5.0 + Gradle wrapper 8.9（腾讯云镜像）+ Compose 编译器 2.0.21；`kotlin.compiler.execution.strategy=in-process`。
- 关键坑：OkHttp 4 二进制帧用 `ByteString.of(*bytes)`（带 offset 的重载已废弃且按错误处理）；Compose 手势 API `awaitEachGesture`/`awaitFirstDown` 在 `androidx.compose.foundation.gestures`，`awaitPointerEvent` 是 AwaitPointerEventScope 成员无需导入。
- 验证：assembleDebug 成功；模拟器实测首启设置弹窗、文字输入与保存、绿色气泡展示、长按触发录音流程与失败提示。真实 API Key 的端到端转写未测（无 Key）。
- 交付：APK `voice-notes-v1.0-debug.apk`；仓库 https://github.com/Mackxin/voice-notes-android （公开，MIT），两次提交均已 push。
