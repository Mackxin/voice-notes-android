# 随手说 · VoiceNotes

一个「微信式」语音速记安卓 App（v1.8.0）：**底部输入栏有两种模式——「可按住转文字」和「按住说话」，点左下角按钮即可来回切换，切换带滑动淡入与配色渐变过渡**（对齐微信 8.0.80 的「可按住 转文字」交互）。录音与文字全部保存在本机，语音识别走阿里云百炼 DashScope；声纹光球录音动效、卡片式记录、首页概览、剪贴板快贴一应俱全。

v1.8.0 重点：**长按操作菜单改为横向一排按钮**（上图标下文字，菜单高度小、不会再超出屏幕底部被裁）、**搜索时点空白处自动收起输入法**、**底部输入栏降低高度**（药丸框 52→46dp）、**模式切换改用 spring 弹性动画**（图标缩放+淡入淡出、配色与文字滑动更顺滑）。

v1.7.0 重点：**转成文字的记录只显示文字**（不再显示波形+时长）、**长按菜单向左展开避免文字被截**、**底部状态提示文字去掉**、**输入栏占位文字与空态文字居中**、**首页统计卡新增置顶开关**（设置→外观，可固定置顶或随列表滚动）。

v1.6.0 重点：**长按记录改为就地弹出的紧凑小菜单**（贴在气泡旁、字号更小、无遮罩）、**录音左右滑去掉中间横线**（左右操作块独立反馈）、**多选选中态去掉灰色填充与阴影**（仅保留勾选框 + 边框高亮）。

v1.5.0 重点：**安装包大幅瘦身**（debug 16MB→9.2MB，release 仅 1.1MB）、**点语音气泡即播放**、**长按记录弹出操作面板**（倍速播放 / 语音转文字 / 复制 / 编辑 / 多选 / 删除）、录音左右滑改为**跟手光球 + 图标色块吸附**设计、去掉日期旁的语音时长标签与复制图标、设置页精简并默认收起 API 配置、去掉长按操作时的全屏灰色遮罩。

## 底部两种模式（左下角按钮切换）

| 模式 | 占位文字 | 点按文字区 | 长按后原地松手 | 左滑取消 | 右滑 |
|---|---|---|---|---|---|
| **可按住转文字**（默认，薄荷绿） | 可按住 转文字 | 直接打字（弹键盘） | **语音转成文字并记下** | 丢弃，不保存 | 转文字进入编辑框，可改后再保存 |
| **按住说话**（紫罗兰） | 按住说话 | 直接打字（弹键盘） | **只保存语音文件**（真实时长） | 丢弃，不保存 | 语音转成文字并记下 |

> 切换动效：左下角图标（声波 ⇄ 话筒）淡入淡出并旋转 180°，强调色在薄荷绿与紫罗兰间渐变，占位文字横向滑动切换。录音过程中以按下瞬间的模式为准，避免中途切换造成歧义。

## 交互方式

| 操作 | 效果 |
|---|---|
| 点左下角按钮 | 在「可按住转文字」与「按住说话」之间切换（非打字时）；打字模式下点它则收键盘退回语音模式 |
| 点右侧文字区 | 切换为打字模式，弹出键盘，输入后点右侧按钮保存 |
| 按住输入栏（含左侧按钮） | 直接开始录音，**不会弹出键盘**；出现声纹光球 + 涟漪动效 |
| 按住后往左滑到「取消」 | 光球跟手左移并变红，左侧取消色块填充放大 + 叉号图标放大，松手丢弃 |
| 按住后往右滑到「转文字」 | 光球跟手右移，右侧转文字色块填充放大 + 声波图标放大，松手后调用百炼转写；转文字模式下进入编辑框，按住说话模式下直接记成文字 |
| 原地松手 | 按住说话模式**只保存语音文件**；转文字模式**转成文字记下**（无 API Key 或没听清时提示重试） |

> 录音面板 v1.5.0 重设计：**光球跟手位移**、落入左/右区即变色，**左右操作块随滑动进度连续填充放大**（带图标），操作感强。v1.6.0 按反馈去掉了中间的滑动进度轨道，左右操作块各自独立给出高亮反馈。

## 文字管理与多选

| 操作 | 效果 |
|---|---|
| 点语音记录气泡 | 直接播放/停止该段语音（按当前倍速），气泡边框高亮 + 波形起伏 |
| 点文字记录气泡 | 复制该条文字到剪贴板 |
| **长按任意记录气泡** | 在该记录上方**就地弹出横向操作条**（v1.8.0，上图标下文字、无遮罩、高度小不遮屏）：语音可选「播放 / 1.5x / 2x / 转文字」；有文字的可「复制 / 编辑」；通用「多选 / 删除」。点菜单外区域或按返回键关闭 |
| 点顶栏「多选」图标 | 进入多选模式：每条记录左侧出现勾选框，标题显示「已选 N 项」 |
| 多选下点气泡或勾选框 | 切换该条选中状态 |
| 多选下点「全选 / 取消全选」 | 一键选中或清空当前全部记录 |
| 多选下点「复制」 | 把所有选中记录里有文字的内容拼成多行，复制到剪贴板 |
| 多选下点「删除」 | 二次确认后批量删除所选记录及其语音文件 |
| 多选下按返回键或顶栏 ✕ | 退出多选模式 |

> 纯语音记录（无转写文字）只显示波形 + 时长，不再有 `[语音消息]` 文字说明；它仍可播放、勾选删除，但没有可复制的文字。有转写文字的记录（含语音转成的文字）v1.7.0 起**只显示文字，不再显示波形 + 时长**。

**打字模式的四种退出方式**（收键盘、退回语音模式）：

1. **点记录列表的空白处**
2. 点输入框右侧的向下箭头「收起键盘」按钮
3. 按键盘上的「完成 / Done」键
4. 按手机系统返回键（打字模式下会先收键盘，不会直接退出 App）

> 两种语音模式的输入栏都是纯文字占位（不是可聚焦的输入框），所以长按绝不会误弹输入法；只有短按文字区才会切换成真正的输入框并弹出键盘。发送后也自动回到语音模式。

其余能力：

- **语音文件本地保存**：每次录音写成 WAV 存到 `filesDir/recordings/`，不需要存储权限。
- **查看时长**：语音记录气泡内直接显示真实时长（如 `0:08`），日期旁不再重复标注；旧版本记录为 0:00 时按 WAV 文件大小自动反推修正。**点气泡整体即可播放/停止**，播放时气泡高亮、波形起伏。
- **长按操作菜单**：长按任意记录，在气泡上方就地弹出**横向一排**操作条（上图标下文字、无遮罩、高度小不遮屏），支持语音倍速播放、语音重新转文字、复制文字、编辑、多选、删除。
- **搜索收键盘**（v1.8.0）：搜索框弹出输入法后，点列表空白处自动收起键盘。
- **语音转文字**：对已保存的语音，长按 → 「语音转文字」即可补转文字（需配置 API Key）；录音中左右滑也可实时转写。
- **多选管理**：顶栏进入多选后，支持全选、批量复制文字、批量删除（含语音文件）。选中态仅用薄荷绿勾选框 + 边框高亮表示，气泡本身不加灰色填充、不加阴影（v1.6.0）。
- **暗黑模式**：设置页可选「跟随系统 / 深色 / 浅色」，默认深色。
- **设置页**：点右上角齿轮进入独立的全屏设置页（不再是弹窗），含「数据管理 / 外观 / 语音转写」；**API Key / 业务空间 / 模型等配置默认收起**，点「API 配置」才展开，不暴露默认值。
- **统计卡置顶开关**（v1.7.0）：设置→外观→「统计卡固定置顶」，默认开（统计卡固定在列表上方不随滚动）；关掉后统计卡作为列表首项随记录一起滚动。设置即时生效并持久化到本机。
- **数据管理**：设置页可查看记录条数、语音文件数、占用空间；点「刷新」实时读取本机数据，直接显示数据的**本机保存路径**（`notes.json` 与 `recordings/` 目录），两行路径均可点击，通过自定义 DocumentsProvider 在系统「文件」应用里直接显示「随手说本机数据」目录（含 `notes.json` 与 `recordings/`）；并可「清除语音文件（保留文字）」或「清空全部数据」（二次确认）。已移除原先的实时记录列表。
- **全局搜索**：首页右上角放大镜可按记录正文、语音标记和显示时间过滤全部记录，返回键或箭头退出搜索。
- **剪贴板快贴**：打开 App 或从后台回来时自动检测复制内容，输入栏上方出现快贴条，点「粘贴」直接填入草稿；复制变化会实时更新。
- **新视觉**：首页概览卡、卡片式记录（语音只显示波形/时长、文字不显示复制图标）、悬浮输入栏、声纹光球录音页；深色为深蓝底 + 薄荷绿，浅色为雾白底 + 青绿。
- **本地优先**：百炼连不上时仍照常录音保存；按住说话模式下原地松手完全不请求转写。

## 安装包体积（v1.5.0 优化）

| 构建 | v1.4.0 debug | v1.5.0 debug | v1.5.0 release |
|---|---|---|---|
| 大小 | 16 MB | 9.2 MB | **1.1 MB** |

> 原因：旧版依赖 `material-icons-extended`（classes.jar 约 36MB、上万个图标），实际只用 16 个。v1.5.0 改用轻量的 `material-icons-core`（约 850KB），缺失的 6 个图标用官方标准 pathData 本地定义（`AppIcons.kt`）；release 构建再叠加 R8 代码压缩 + 资源压缩（`isMinifyEnabled` / `isShrinkResources`），最终只有约 1.1MB。release 与 debug 同签名，可直接覆盖安装。

## 快速开始（零基础）

1. 打开[阿里云百炼控制台](https://bailian.console.aliyun.com/) → 模型设置 → API Key，创建一个 Key。
2. 用 Android Studio 打开本项目（或用命令行 `./gradlew assembleDebug`），把 APK 装到安卓 8.0 以上手机。
3. 点右上角齿轮进入「设置」页，填入 API Key，其余保持默认，点「保存设置」返回。
4. 系统弹麦克风权限时点「允许」，即可按住说话。

> API Key 仅写入手机本地的 SharedPreferences，代码里没有硬编码，仓库里也不会有你的 Key。
> 识别模型默认为 `paraformer-realtime-v2`，可在设置里更换为百炼支持的其他实时识别模型。

## 技术栈

- Kotlin 2.0.21 + Jetpack Compose（Material 3）
- AudioRecord 采集 16kHz / 16bit / 单声道 PCM，每 100ms 一帧；同一帧写入 WAV 文件
- OkHttp WebSocket 双向流式对接百炼实时语音识别
- 笔记用 JSON 存 `filesDir/notes.json`，语音用 WAV 存 `filesDir/recordings/`，完全离线可读
- Material 3 深色 / 浅色 / 跟随系统三档主题

## 百炼接口说明

采用**实时识别**而非文件转写：文件转写接口需要公网可下载的音频 URL（Alibaba Cloud 2026a），手机本地录音无法满足；实时接口直接推二进制 PCM 帧，松手后发送 `finish-task` 即可拿到定稿文本（Alibaba Cloud 2026b, 2026c）。

请求域名默认 `wss://dashscope.aliyuncs.com/api-ws/v1/inference`。如果在设置里填了业务空间 ID，则改用 `wss://{WorkspaceId}.cn-beijing.maas.aliyuncs.com/api-ws/v1/inference`。两个域名均由官方文档给出（Alibaba Cloud 2026b）。
